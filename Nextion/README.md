Interface de Supervisão Nextion

Esta pasta contém os arquivos da interface gráfica desenvolvida no Nextion Editor para o sistema de supervisão e interação com a extrusora de filamento PET.

A interface permite ao operador interagir com o equipamento por meio da tela Nextion, realizando comandos e acompanhando informações relacionadas ao funcionamento do sistema.

Arquivos disponibilizados

Interface_Extrusora.HMI: arquivo editável do projeto da interface, desenvolvido no Nextion Editor.

Interface_Extrusora.TFT: arquivo compilado para utilização na tela Nextion.

Ambiente de desenvolvimento

Software: Nextion Editor.

Interface: display Nextion.
