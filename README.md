Extrusora de Filamento PET

Este repositório disponibiliza os arquivos desenvolvidos para o projeto de uma extrusora de filamento PET, elaborado como Trabalho de Conclusão de Curso do Técnico em Automação Industrial do Instituto Federal Sul-rio-grandense (IFSul).

Estão disponibilizados os códigos e arquivos utilizados no sistema de controle da extrusora, incluindo:

Arduino: código-fonte utilizado no Arduino para o controle e funcionamento do sistema.

Nextion: arquivos da interface gráfica desenvolvida no Nextion Editor, utilizada para a interação e supervisão do equipamento.

Organização do repositório

Arduino/: contém o código-fonte utilizado no Arduino.

Nextion/: contém os arquivos da interface desenvolvida no Nextion.
