Código-fonte Arduino

Esta pasta contém o código-fonte desenvolvido para o Arduino Uno, utilizado no sistema de controle da extrusora de filamento PET.

O programa é responsável pelo controle das funções automatizadas do equipamento, incluindo o controle de temperatura por meio de um controlador PID e o acionamento do motor de tração.

Arquivo disponibilizado

Extrusora_PET.ino: código-fonte principal do sistema de controle.

Ambiente de desenvolvimento

Plataforma: Arduino Uno.

Linguagem de programação: C/C++.

Ambiente de desenvolvimento: Arduino IDE.
